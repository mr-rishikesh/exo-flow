✅ Core APIs
   • GET /articles     - List all articles
   • GET /events       - List all events
   • GET /playbooks    - List all playbooks

✅ Filtering
   • category          - Filter by main category
   • subcategory       - Filter by subcategory
   • type              - Filter event type
   • q                 - Full-text search

✅ Sorting
   • latest            - Newest first (default)
   • trending          - By clicks/registrations
   • downloads         - By download count

✅ Pagination
   • page              - Page number (default: 1)
   • limit             - Items per page (default: 10)

✅ Analytics
   • POST /articles/:id/click       - Track views
   • POST /events/:id/register      - Track registrations
   • POST /playbooks/:id/download   - Track downloads

✅ Dynamic Categories
   • GET /articles/categories
   • GET /events/types
   • GET /playbooks/categories

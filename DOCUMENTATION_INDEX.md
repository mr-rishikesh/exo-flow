## 🔑 Key Information

### Database
- **Type:** MongoDB
- **Connection:** MONGO_URI environment variable
- **Collections:** articles, events, masterclasses, playbooks, magazines, leads
- **Auto-seeding:** Yes, on first startup from /data/*.json files

### Server
- **Framework:** Express.js
- **Language:** Node.js
- **Port:** 3000 (configurable)
- **Authentication:** Admin login with email/password
- **Session:** Express-session with secure cookies

### API
- **Format:** RESTful JSON
- **Base URL:** http://localhost:3000
- **Admin Panel:** http://localhost:3000/admin/login
- **Health Check:** http://localhost:3000/health
